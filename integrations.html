Developer Experience

One function call to add AI quality gates

QAVE ships with a Python SDK, JavaScript SDK, and a fully documented REST API. Add AI eval checks to any pipeline without changing your existing workflow.

evaluate_response.py 
from qapitol import QAVEClient

client = QAVEClient(api_key="qv_your_key")

# Evaluate an LLM response
result = client.evaluate(
    model="gpt-4o",
    prompt="Explain our refund policy",
    response=llm_response,
    checks=[
        "hallucination",
        "toxicity",
        "pii_exposure",
        "policy_compliance"
    ]
)

if result.score < 0.85:
    flag_for_review(result)
